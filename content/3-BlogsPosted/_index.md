This section lists the blogs I have posted to the [AWS Study Group](https://www.facebook.com/groups/awsstudygroupfcj):

### [Blog 1 - 7 IAM Best Practices to Better Protect Your AWS Account](3.1-Blog1/)
This blog shares 7 key IAM principles to secure your AWS account more effectively, ranging from avoiding the Root User for daily tasks, enabling MFA, applying the principle of least privilege, to prioritizing temporary credentials and IAM roles for workloads.

### [Blog 2 - Managing Sensitive Information on AWS: When .env Files Are No Longer the Optimal Choice](3.2-Blog2/)
This blog analyzes the risks of continuing to use .env files, hardcoding secrets, or embedding them into Docker images in production environments, while introducing AWS Secrets Manager and Parameter Store as robust configuration security solutions.

### [Blog 3 - What I Like Most Is That Auto Scaling Isn't Just for Massive Systems](3.3-Blog3/)
This blog shares practical insights on implementing Auto Scaling even for small applications or learning projects, enabling systems to dynamically adjust resources, optimize costs, and maintain performance under changing workloads.
