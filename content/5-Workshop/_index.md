# Comprehensive Build and Deployment of an AI-Powered Personal Finance Platform on AWS

#### Overview

The **Cloud Finance Platform** is an intelligent personal finance management solution leveraging Artificial Intelligence (AI/NLP) and Optical Character Recognition (OCR) built upon a **Cloud-Native Microservices** architecture.

In this hands-on workshop series, we will learn how to configure secure network infrastructure, initialize distributed data tiers, containerize microservices, run them on serverless Amazon ECS Fargate clusters, and distribute the application via Amazon CloudFront.
